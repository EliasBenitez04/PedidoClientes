LOGOS GOTITAS

El sistema ya tiene preparados tres archivos de imagen.

Copiar los logos reales dentro de public/images con estos nombres:

1. logo-gotitas.png
   - Logo para fondo claro.
   - Se usa en la pantalla de login.
   - Recomendado: PNG transparente, ancho aproximado 300-600 px.

2. logo-gotitas-blanco.png
   - Logo claro/blanco para fondo oscuro.
   - Se usa en el sidebar y sector oscuro del login.
   - Recomendado: PNG transparente, ancho aproximado 300-600 px.

3. favicon-gotitas.png
   - Ícono de la pestaña del navegador.
   - Recomendado: PNG cuadrado 64x64 o 128x128.

Si los archivos todavía no existen, el sistema muestra GOTITAS como texto automáticamente.
No hace falta modificar Blade ni CSS al agregar los logos: solo copiar las imágenes con esos nombres.
